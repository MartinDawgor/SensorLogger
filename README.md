# AIDA SensorLogger

Локальный диагностический комбайн и сенсор-логгер под Android (`minSdk 24`, `targetSdk 35`) в строгом UI без рекламы, облачных аккаунтов и платных подписок. Пишет сырую и агрегированную телеметрию со всех доступных датчиков HAL, GPS, BLE, микрофона и системных подсистем, на месте прогоняет статистику и выдает готовые отчеты.

---

## Использование

1. Ставишь `app-release.apk` (или собираешь из сорцов, см. ниже).
2. На главном экране выбираешь либо готовый 1-tap сценарий, либо проваливаешься в нужный модуль.
3. В нижнем доке выставляешь базовый polling rate (`~5 / ~20 / ~50 / ~100 Гц`) и жмешь старт записи CSV.
4. Для длинных прогонов при тушении экрана оставляй включенным `Foreground Service` в параметрах CSV (по умолчанию активен). При желании кидай быстрые маркеры (метки событий) прямо поверх текущей сессии.
5. После стопа открываешь вкладку `Логи и Отчёты` - сразу смотришь вердикты по отклонениям и выгружаешь в нужный формат.

## Режимы работы и мануал по разделам

### 1. Сценарии (1-tap на главном экране)
Пресеты для старта без ручного тыканья галочек:
- `Поездка в авто` - включает акселерометр, гироскоп, линейное ускорение, вектор вращения и GPS на `~20 Гц`, префикс файлов `drive`.
- `Вибродиагностика` - акселерометр + линейное ускорение на макс. частоте `~100 Гц`, префикс `vibro` (подходит под БПФ-спектр).
- `Пешая прогулка` - шагомер/счетчик шагов, акселерометр, свет, барометр на `~20 Гц`, префикс `walk`.

Тап по сценарию применяет пресет только в idle (во время активной записи блокируется, чтобы не побить структуру CSV).

### 2. Датчики (Каталог HAL и Инспектор)
Список всех сенсоров устройства с разделением по friendly-именам, категориям (`Движение`, `Среда`, `Позиция`, `Биометрия`, `Прочие`) и live-превью.
- Фильтры и пресеты (`IMU`, `Среда`, `Позиция`) спрятаны под кнопку фильтров.
- Доп. источники (`GPS`, `Шумомер`, `BLE маяки`, `Батарея/Яркость/Сеть`) подключаются отсюда же как виртуальные каналы в общий лог.
- Тап по любому датчику открывает **Инспектор**:
  - Real-time таблица каналов (`min .. max`, `|V|`, статус точности HAL).
  - Интерактивная осциллограмма (поддерживает `pinch-to-zoom` / сдвиг жестами и переключатель `Авто-зум` / `Стаб. шкала`).
  - **Rate Override**: принудительная переопределенная частота опроса именно для этого датчика (например, аксель на 100 Гц, барометр на 5 Гц). Работает отдельно от глобального свитча в доке.
  - **Soft-калибровка (rootless)**: системный EEPROM/HAL без рута менять нельзя, поэтому девайс кладется на ровную поверхность, жмешь `Калибровать ноль` - собирается базовый оффсет дрейфа в покое и вычитается внутри софта (для `TYPE_ACCELEROMETER` вертикальная ось сохраняет `1g = 9.81 м/с²`). Можно в любой момент отключать тумблером или сбросить.
  - Паспорт железа: vendor, `maxRange`, `resolution`, `maxFrequencyHz`, `powerMa`, `wake-up`.

### 3. Живой монитор
Мульти-осциллограф для закрепленных датчиков (кнопка пина в списке или в инспекторе).
- Отрисовка идет через `drawWithCache`, при скролле обновления фризятся, чтобы список держал стабильные 60/120 FPS без дропов.
- Показывает реальную измеренную частоту в Гц и статус точности каждого канала.

### 4. Инженерные приборы
Набор standalone-инструментов поверх текущих показаний:
- **G-метр и Виброметр**: текущая перегрузка в `g`, пиковое значение с ручным сбросом, шкала до `3g` и линейная вибрация без гравитации.
- **Спектр вибраций (FFT / БПФ)**: оконный Radix-2 FFT по буферу акселерометра - строит амплитудный спектр по бинам и выделяет доминирующую резонансную частоту в Гц.
- **Инклинометр и Компас**: пузырьковый уровень (`pitch / roll`) с обнулением нуля под кривой стол/торпеду + магнитный азимут на север.
- **Барометр / Альтиметр и Шумомер**: оценка барометрической высоты + уровень звука с микрофона в `dBFS` и ориентировочных `дБ SPL` (требует `RECORD_AUDIO`).

### 5. GPS / GNSS Трекер
Сырые координаты (`lat`, `lon`), высота, скорость (м/с и км/ч), курс (bearing), точность фикса, провайдер. Включается как источник записи для последующего экспорта маршрута в `KML`. Требует `ACCESS_FINE_LOCATION`.

### 6. Bluetooth LE Сканер
Поиск ближайших BLE-рекламных пакетов: имя устройства, MAC, `RSSI` (дБм), краткий raw/manufacturer payload. Для Android 12+ требует `BLUETOOTH_SCAN` / `BLUETOOTH_CONNECT`, для старых SDK - геолокацию.

### 7. Правила, Аннотации и Чёрный ящик
- **Режим «Чёрный ящик»**: держит в RAM кольцевой буфер за последние `30 сек` (до 6000 сэмплов) без постоянной долбежки флеша. Можно сбросить в CSV вручную кнопкой или автоматически по правилу.
- **Умные правила (Smart Rules)**: реактивные триггеры вида `условие -> действие` с cooldown-таймером. Условия: перегрузка `G >= порог`, темнота `люкс <= порог`, шум `dBFS >= порог`, таймер автостопа `сек`. Действия: вставка маркера, старт записи, стоп записи, сброс Чёрного ящика в файл.
- **Пресеты аннотаций**: настраиваемые кнопки быстрых меток (`START`, `CHECK`, `EVENT` и свои), вставляют строку `user.marker` прямо в текущий лог.

### 8. Стрим и Web-панель
Два независимых канала наружу:
- **Локальный Wi-Fi Web-дашборд**: поднимает встроенный HTTP-сервер на порту `8090` (`http://<ip-телефона>:8090`). Открываешь в браузере на ПК в той же сети - получаешь live-значения (`/api/live`) и список готовых CSV для скачивания (`/download/<file>`) без поднятия стороннего бэкенда.
- **Потоковый экспорт (Real-Time)**: раз в секунду пушит пачки JSON на ваш `HTTP POST` endpoint или брокер `MQTT 3.1.1 (TCP)` со статистикой доставленных пакетов и ошибок.

### 9. Оборудование (AIDA64-подобные разделы)
Четыре диагностических экрана по железу и ОС:
- `Система и CPU`: бренд, модель, SoC/hardware, ABI, версия ОС/API, uptime, текущие/мин/макс частоты по каждому ядру.
- `Батарея и Термо`: процент, статус зарядки, технология, вольтаж, ток (мА), температура батареи и системные thermal zones.
- `Память и Экран`: RAM (`used / free / total`), внутренняя флеш-память, разрешение, `dpi`, refresh rate в Гц.
- `Сеть и Система`: активный транспорт (`Wi-Fi / Cellular`), SSID/RSSI, IP, яркость экрана, сводка по количеству датчиков HAL.

### 10. Логи и Отчёты
Менеджер записанных CSV и встроенный анализатор (`SessionAnalyzer`):
- В параметрах CSV настраивается разделитель (`,` RFC-4180 или `;` + UTF-8 BOM под русскую локаль Excel), формат времени (`Unix ms`, `ISO-8601`, `сек от старта`), префикс имени файла и `Foreground Service`.
- Поиск и сортировка через кнопку `Фильтры`.
- При выделении чекбоксами ровно двух сессий появляется кнопка `A/B` - открывает визуальное и статистическое сравнение (`mean`, `σ`, вердикты и два зуммируемых графика друг под другом).
- Тап по одной сессии открывает просмотрщик с 4 вкладками (`Вердикты`, `Таблица`, `График` с жестами, сырой `CSV`) и меню экспорта:
  - `HTML-отчёт`, `PDF-отчёт` (через системную печать Android Print Framework), `Wide CSV` (выровненная по времени таблица под Excel), `Markdown (.md)`, `JSON`, `SQLite (.db)`, `KML`, `ZIP-архив` (одиночный и пакетный), исходный `RAW CSV`.

## Сборка из исходников

Требования: Android SDK (`compileSdk 35`, `minSdk 24`) и **JDK 17** (Gradle 8.11.1 + Kotlin DSL не заводятся на JDK 21+/27 без явного `JAVA_HOME`).

```powershell
$env:JAVA_HOME = "C:\Android\jdk-17"
$env:Path = "C:\Android\jdk-17\bin;$env:Path"

# прогон unit-тестов (20 тестов)
.\gradlew.bat testDebugUnitTest

# сборка debug и release APK (R8 + shrinkResources)
.\gradlew.bat assembleDebug assembleRelease
```

Артефакт на выходе: `app/build/outputs/apk/release/app-release.apk`.

## Примечания по железу (RTFM)
- В части Android-устройств драйвер гироскопа в покое выдает мелкий тепловой шум/дрейф нуля. Без root-прав зашить калибровку в NVRAM/persist нельзя - используй встроенную soft-калибровку в инспекторе датчика.
- Высокие частоты (`FASTEST`) на пачке из 5+ датчиков одновременно + BLE-скан ощутимо греют контроллер и садят АКБ. Для долгих замеров ограничивай выбор датчиков или ставь `rate override`.
